\chapter{使用注意事项}
\setchapterheader{附录 B\quad 使用注意事项}
调试和使用机器人时，请注意以下事项。


\begin{enumerate}
\item 调试\textbf{全程使用吊架}，防止程序错误导致失控损坏。
\item 开机时关节勿处限位、勿阻挡回零；面朝上平躺、地面平坦防滑、脚底无异物。
\item 起身/收纳动作波及范围 3m$\times$3m 内不得有杂物；禁止运动中人为干扰（策略为盲走）。
\item 禁止快速反复切换模式；禁止行走时拎起机器人双脚悬空。
\item 电池未正确安装禁止开机；低电量勿跑策略。
\item 同一时间只允许一个控制源（APP/手柄直连/本 SDK 程序不要同时控制）。

\end{enumerate}
